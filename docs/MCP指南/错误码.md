# MCP 错误与恢复指南

> 面向 MCP 调用者。优先读取结构化字段，不解析日志文本，也不对所有失败统一重试。

## 1. 两种错误来源

工具调用失败时读取 `AgentResult.error`：

- `code`：稳定错误码。
- `message`：面向人的说明，不作为程序分支依据。
- `retryable`：该次工具调用是否具备重试可能。
- `agent_hint`：建议的下一步。
- `details`：可选诊断数据。

后台 Job 已创建后，应改读 `read_job.data.recovery`。此时 `recovery.classification`、`requires_user_action` 和 `next_actions` 比静态错误码更接近当前状态。

## 2. 公共错误码

| 错误码 | 含义 | 调用者动作 |
|---|---|---|
| `JOB_NOT_FOUND` | Job 不存在 | 核对 `job_id`；不要猜测或创建同名 Job |
| `LOCAL_ARCHIVE_NOT_FOUND` | 本地尚无归档 | 确认用户意图后创建归档 Job |
| `REMOTE_FETCH_FAILED` | 论坛请求失败 | 查看 `retryable` 和 `agent_hint`；避免立即连续重试 |
| `REMOTE_LOGIN_REQUIRED` | Cookie 缺失或登录失效 | 停止自动调用，请用户更新 Cookie |
| `REMOTE_MAINTENANCE` | 论坛维护 | 等待后重试原流程 |
| `REMOTE_ACCESS_PAUSED` | 反爬保护已暂停远端访问 | 停止远端调用，等待或由用户恢复访问 |
| `REMOTE_SOFT_BLOCK` | 远端返回 WAF/反爬拦截页，例如 `Sorry, you have been blocked` | 不要判定资源不存在；等待自动重试或更换远端节点后继续观察原 Job |
| `REMOTE_THREAD_PERMISSION_REQUIRED` | 阅读权限不足 | 请用户提供有权限的账号配置 |
| `IMAGE_TARGET_NOT_DOWNLOADED` | selected 图片未下载或未能与目标资产重新关联，且没有更具体的远端拦截分类 | 先读取逐图诊断；只在确认不是 WAF、HTML 页面或可恢复传输问题后，再决定是否重新创建任务 |
| `UNEXPECTED_REMOTE_PAGE` | 页面类型与预期不符 | 核对 tid、登录状态和帖子可见性 |
| `EXPORT_PRECHECK_FAILED` | 本地归档不满足导出条件 | 先完成或修复归档 |
| `INVALID_ARGUMENT` | 参数类型、范围或组合无效 | 根据 Capability input schema 修正参数 |
| `INTERNAL_ERROR` | 未分类内部错误 | 停止盲目重试，报告 request/job 上下文并检查日志 |

项目可能返回更具体的领域错误码；调用者仍按 `retryable`、`agent_hint` 和 Job Recovery 处理。

## 3. Job Recovery 决策表

| classification | 是否自动新建 Job | 动作 |
|---|---:|---|
| `completed` | 否 | 读取结果 |
| `use_partial_result` | 否 | 使用可用结果并披露不完整 |
| `continue_waiting` | 否 | 轮询原 `job_id` |
| `automatic_retry` | 否 | 等待 `next_retry_at` |
| `automatic_recovery` | 否 | 等待 daemon 恢复 |
| `user_action_required` | 否 | 停止并请求用户处理 |
| `inspect_failure` | 暂不 | 先读取 `read_job_events` |
| `stopped` | 否 | 停止轮询；按新意图决定是否重建 |

只有在原 Job 已终止、Recovery 没有恢复路径，并且用户仍明确需要该操作时，才考虑创建新 Job。

图片下载任务的分类优先级：

1. 响应正文命中 WAF 签名时使用 `waf_response`；selected 任务使用 `REMOTE_SOFT_BLOCK`，即使外层 HTTP 状态是 200/403/404。
2. 图片响应缺少有效结束标记或长度不完整时使用 `truncated_image`；实现会先尝试一次 Range 续传，再消耗 Job 的延迟重试预算。
3. 只有排除 WAF/HTML 和传输截断后，selected 任务才使用 `IMAGE_TARGET_NOT_DOWNLOADED`。

## 4. 远端访问暂停

`REMOTE_ACCESS_PAUSED` 通常表示系统正在保护账号和 IP。调用者应：

1. 停止 `remote_read` 和依赖远端的 Job 创建。
2. 向用户报告暂停原因。
3. 等待 daemon 自动探测，或由用户在 Web 控制台恢复。
4. 恢复后重新检查原 Job 或重新执行只读探测。

不要通过高频重试验证是否恢复。

## 5. 人工排障

MCP 内优先调用：

- `read_job(job_id=...)`
- `read_job_events(job_id=...)`
- Resource `yamibo://jobs/<job_id>/status`
- Resource `yamibo://jobs/<job_id>/events`

只有需要操作主机时，才使用 CLI 或 Web 日志页面。
