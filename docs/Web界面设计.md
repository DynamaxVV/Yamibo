# 百合会归档助手 WebUI 功能与设计文档

> 版本：2.1 设计修订，已完成本轮界面实施与抽样视觉验收 | 更新日期：2026-09-23 | 视觉参考：`ui渲染.png` 的纸墨语言。权威设计决策见根目录 `DESIGN.md`，页面规格与实施结果见 `docs/Web-UI-v2.1-设计与执行方案.md` 和 `docs/Web-UI-v2.1-视觉验收记录.md`。PC/宽屏以用户当前 Chrome 窗口实际尺寸与分辨率为验收基准；技术架构描述当前项目，功能矩阵中的后续能力仍以实际数据契约为准。

## 1. 技术架构

### 1.1 前端栈

- **核心框架**：React 18 + TypeScript + Vite 6
- **样式引擎**：Tailwind CSS v4（基于 `@tailwindcss/vite`）
- **设计原语**：shadcn/ui 原语 + 自研 Modern Editorial Tokens
- **动效引擎**：`motion`（物理纸墨微弹与微阻尼触觉反馈）
- **图标体系**：Lucide Icons (`lucide-react`)，统一 `1.5px/1.75px` 细线条
- **数据管理**：`@tanstack/react-query` v5（自动缓存与后台静默刷新）
- **路由系统**：`react-router-dom` v6
- **字体系统**：多语言三轨回退（Geist/Inter 界面正文 + Avenir Next/PingFang SC 编辑标题 + JetBrains Mono 监控等宽）；阅读器保留独立衬线字体设置。

### 1.2 后端接入

- **API 服务**：`src/yamibo_mcp/web_fastapi/` — 基于 FastAPI 的 REST 路由与依赖注入
- **静态资源**：`src/yamibo_mcp/web/static/` — Vite 编译输出产物直接由 FastAPI 服务，支持 SPA 兜底路由
- **媒体挂载**：`/media`（封面、楼层图片）、`/fonts`、`/artifacts`

### 1.3 源码结构

```
c/
├── src/
│   ├── api/client.ts              # 纯 TypeScript API 契约与统一请求器
│   ├── components/                # 共享组件 (Layout, ThreadReader, Badge, PaginationControls 等)
│   ├── context/                   # I18nContext, ThemeContext, TaskStatusContext
│   ├── lib/utils.ts               # cn() 样式工具函数
│   ├── pages/                     # 15 个功能业务页面
│   ├── styles/                    # 专有局部样式 (reading.css, chat.css, settings.css)
│   ├── index.css                  # Tailwind v4 全局 Design Tokens 与高对比度报刊样式
│   └── App.tsx                    # 全局路由、QueryClient 与 Provider 组合
├── public/                        # 静态图片、图标与字体
├── tsconfig.json                  # 路径别名 @/* 与编译约束
└── vite.config.ts                 # Tailwind 插件与产物输出配置
```

## 2. 核心页面功能矩阵

### 2.1 内容与任务优先控制台 (`/`)
*沿用 `ui渲染.png` 的纸墨配色与出版物节奏，不复刻其装饰标签和虚构内容：*

| 区块 | 功能与视觉特征 |
|------|------|
| **紧凑页头** | 页面用途与当前归档状态清楚，不显示以帖子 TID 假扮的期号或无语义栏目号。 |
| **真实统计与异常** | 暖杏卡显示归档帖子、作品系列、导出档案及队列状态；标签准确对应实际字段。异常与待处理任务应可进入详情。 |
| **最近归档** | 先保证帖子标题两行可辨，日期使用短格式；保留真实的版块筛选。热门、趋势、编辑精选仅在有独立数据语义后出现。 |
| **帖子入口** | 首页通栏最近归档表的标题直接通向帖子；不再以重复第一条内容的侧栏占用标题宽度。无收藏能力时不显示 `SAVE`。 |

### 2.2 任务列表 (`/jobs`)

| 功能 | 说明 |
|------|------|
| 状态筛选栏 | 药丸分段控件：全部 / 排队 / 运行 / 重试 / 暂停 / 成功 / 部分 / 失败 / 中断，实时展示各项数字小胶囊。 |
| 失败类型二级筛选 | 当处于失败状态时，动态激活 WAF 拦截/登录失效/权限限制等二级维度过滤。 |
| 批量操作浮动胶囊 | 勾选多项时滑出工具条：批量重试、批量暂停/恢复、批量安全删除。 |
| 任务数据表格 | 任务目的与关联帖子是主信息，状态、进度和时间是辅助信息；内部类型与阶段放到可展开技术详情。窄屏改为任务卡。 |
| 快速安全删除 | 支持按状态一键清空全部失败/已完成任务，二次确认弹窗防误触。 |

### 2.3 任务详情 (`/jobs/:id`)

| 功能 | 说明 |
|------|------|
| 核心属性卡片 | 双列对齐的工整属性卡片（包含 TID、阶段、进度、Worker ID、租约、重试次数等）。 |
| 失败诊断分析 | 首屏显示人可读原因、最近发生时间和下一步；技术原文可展开，文字与背景满足对比度要求。 |
| 事件时间轴 | 最近事件优先，可按失败/状态筛选，长历史分页或展开；不把数百条 JSON 默认铺开。 |
| 操作控制 | 支持单任务重试（Rerun）、暂停/恢复（Pause/Resume）、以及帖子楼层编号异常时的一键全量重新同步。 |

### 2.4 贴子归档列表 (`/threads`)

| 功能 | 说明 |
|------|------|
| 检索与多维筛选 | 搜索放大镜输入框（即时过滤标题、作者、汉化组）、状态筛选下拉、时间跨度下拉。 |
| 版块药丸标签栏 | 横向排列论坛所有有效版块及其帖子总数，深栗红实心高亮当前选中项。 |
| 多列双向排序 | 发布时间、同步时间、回复数、最后回复时间均支持点击升序/降序。 |
| 批量归档操作 | 支持批量勾选并一键提交重新归档或批量删除。 |
| 标题优先布局 | 桌面标题目标至少 320px 或两行可辨；先折叠次级列。手机使用标题优先卡片，不允许隐藏溢出导致信息不可达。 |

### 2.5 贴子详情与独立沉浸阅读器 (`/threads/:tid`)

| 功能 | 说明 |
|------|------|
| 顶部操作条 | 返回列表、重新同步（Resync）、建立向量索引（RAG Index）、导出离线档案（Export）、删除（Delete）。 |
| 属性总览网格 | 归档属性保留编辑能力，但放在阅读入口之后的可展开区域。 |
| **独立沉浸阅读模式 (Zen Mode)** | **快捷键 `R` 或点击按钮一键进入全屏阅读，按 `Esc` 退出。自动隐藏侧边栏与顶栏，版心流体居中为 768px 黄金阅读宽度。** |
| **纵向空间最大化** | **彻底移除顶部厚重横条，阅读控制项收敛为底部居中的轻量半透明悬浮胶囊，保证竖向漫画/长图 100% 纵向完整展开。** |
| 阅读排版调节 | 底部浮动胶囊支持 **思源宋体 (Serif) / 现代黑体 (Sans)** 一键切换、字号 `A- / A+` 缩放、楼层快速跳转。 |

## 3. 视觉色彩与设计 Token

### 3.1 核心调色（借鉴 `ui渲染.png` 的纸墨语言）

* **纸墨基底**：
  * Light 模式：`#FFFDF4`（温润典藏米白纸感），卡片使用 `#FFFDF8`，重点卡片使用 `#FAF3E3`。运行时默认主题必须同步使用这套纸墨变量，避免子页退回旧灰蓝色。
  * Dark 模式：`#120E0C`（深烘茶褐黑，杜绝刺眼纯黑），卡片使用 `#1A1412`。
* **文字高对比度**：
  * 正文与标题：`#12100E`（深沉浓郁的炭墨黑），对比度高达 **14:1**。
  * 辅助信息：`#5C5248`（清晰深茶灰），绝不使用发虚发淡的浅灰字。
* **点睛深栗红**：
  * 主品牌色：`#682516`（实心深印朱红），用于侧边栏激活项、Tab 下划线、主操作按钮。
* **分割线条**：
  * 边框色：`#D8CAB4`（典藏淡金驼细线），内行分割线 `#EAE0D0`。

### 3.2 动效设计 (The Digital Press)

* **微弹展开曲线**：`cubic-bezier(0.16, 1, 0.3, 1)`（200ms ~ 300ms），用于全屏阅读模式展开与侧边栏折叠。
* **状态与按钮微弹**：`cubic-bezier(0.34, 1.56, 0.64, 1)`（180ms ~ 220ms），用于状态 Badge 流转与主按钮点击。
* **物理触觉反馈**：交互卡片带有微小下沉回馈 `scale(0.996)`。

## 4. 全局子页面通用规范

所有子页面先遵循 `DESIGN.md` 的页头、状态、文字与操作层级，再复用基础颜色和边框。`Series`、`Review`、`Forums`、`Logs`、`Rag`、`Exports`、`Settings` 等页面需要按业务内容重新分配布局，不能只通过全局样式换肤：

1. **表格容器 (`.table-wrap`)**：沿用典藏细金边框和暖白底，但各页面自己定义主列与次列。
2. **表头 (`table thead th`)**：统一采用暖米灰底色（`#EEE6D8`）、Mono 等宽大写字体标签与清晰对比。
3. **按钮体系**：
   * `.btn-primary`：深栗红实心底、纯白文字。
   * `.btn-subtle`：象牙白底、细金边框、深黑文字。
   * `.btn-danger` / `.btn-danger-outline`：朱红实心 / 空心警示。
4. **响应式**：页面级不横向溢出，且全部主要内容可到达；必要时使用明确的表格内滚动或手机卡片，禁止用 `overflow-x: hidden` 静默裁切。
