## 补充视觉复验：渲染图语言、密度与字体

- **参考边界**：使用 `ui渲染.png` 的暖象牙纸、深栗红、金驼细线、较实的出版物衬线标题和双栏节奏；不添加样张中的期号、虚构精选、热门标签或假文章。首页右栏从真实最近帖子取标题、作者、日期与回复数。
- **根因修正**：旧 `ThemeContext` 默认主题在运行时将 `--font-serif`、`--bg-muted`、`--border` 等覆盖成 Space Grotesk 和灰蓝色；已统一为 `editorial` 默认主题，并配套深色变量。抽查设置页实际计算值：`--font-serif` 为 Baskerville/Songti 栈、`--bg-muted` 为 `#f6efdf`。
- **PC 1163×684 内容区**：目视复核 `/`、`/threads`、`/jobs`、`/series`、`/series/285`、`/forum`、`/threads/160097`、`/rag`、`/review`、`/exports`、`/logs`、`/settings`、`/chat`。首页已改为暖纸报刊页头、真实状态卡、最近归档/阅读入口双栏；列表页首屏有连续多行真实数据；审核操作保持单行，过宽内容在表格内滚动。检索尚无查询结果，对话服务不可用时检查其真实空状态，未将模拟结果写入正式数据。
- **手机约 390×844**：复核首页、帖子、任务列表及展开的导航抽屉；帖子卡片压缩后首屏可见约 6 条标题，任务卡片约 4 条；中日英混排标题可换行。页面与导航的 `scrollWidth` 未超过 `clientWidth`。手机抽屉使用完整品牌和底部控件。
- **侧栏收起**：64px 桌面状态用居中的 `Y` 代替完整品牌，语言与主题按钮纵向排列；实测侧栏 `scrollWidth === clientWidth`，顶部文字和底部图标均未越界。
- **深色**：复核首页与手机帖子列表，暖深褐背景、浅色标题、卡片和分割线有明确层级。页面切换有短暂颜色过渡，截图需待过渡结束后判读。
- **仍需区分**：帖子正文阅读器可使用用户保存的字体设置，故个别帖子的正文粗细不等同于全站标题字体；远端头像和归档图片是否可加载属于资源状态。`npm run build` 通过，仍有已有的大 chunk 提示。
