> 实施进展：已完成内置运行器、对话页面重构与隔离验证，并通过 gemini-3.7-flash-low 的真实模型初步联调；论坛实网、长期稳定性与 NAS 部署尚未验收。以下保留需求/设计基线，具体实现差异与配置见[实现与配置](内置Agent实现与配置.md)。

## 1. 背景与目标

现有对话页面依赖外部 Hermes，用户反馈经常无法连接、响应慢和通信不畅；Hermes 再通过 Yamibo MCP 操作业务。目标是将对话执行纳入 Yamibo 的本地部署，减少远程服务依赖，保持 MCP 作为业务能力边界。

采用 Pydantic AI，通过本地受限 MCP 调用现有业务能力；不把完整业务注册表直接交给模型。继续使用现有模型服务、业务层和 Job/Daemon。框架替换不承诺消除模型推理、论坛请求或后台任务自身的耗时。

已完成隔离自动化、浏览器及真实模型初步联调，尚未测定生产环境延迟的主要来源。验收必须区分单元/协议测试、浏览器测试与真实模型和部署环境证据。

## 2. 用户与产品范围

唯一用户为项目所有者，不设计多租户、账号体系或团队协作。对话入口仍须受到部署访问控制保护，单用户不等同于无鉴权。

| 编号 | 第一版包含 | 边界 |
|---|---|---|
| R01 | 浏览论坛、搜索、读取远端帖子和本地归档 | 保持论坛远端只读行为 |
| R02 | 创建归档、更新、导出任务 | 实际执行由 Job/Daemon 负责 |
| R03 | 多步查询与整理、基于读取内容生成总结 | 可搜索已有索引，不自动创建索引 |
| R04 | 本地会话、完整工具记录、流式进度与断线重连 | 浏览器连接不拥有执行生命周期 |
| R05 | 专属工作目录中的文件管理 | 受文件归属、授权和路径约束 |
| R06 | 独立业务 AGENTS.md | 默认只读，用户明确要求时允许更新 |

第一版不提供：通用 Shell、代码执行、任意文件访问、NAS 管理、数据库清理/重置、凭据或配置管理、新建 RAG 索引、讨论趋势分析及专用研究报告 Job、多 Agent 编排、跨会话自动记忆、进程重启后自动恢复推理。

“生成一份总结并保存为工作文件”属于 R03/R05；它不意味着开放已有专用研究报告 Job。

## 3. 授权与执行范围

### R07：常规操作与扩大范围

- 明确请求对应的常规操作直接执行，例如“归档这几个帖子”。
- “找一些帖子”只授权查询，不能自行扩展为归档。
- 全版块、全部搜索结果等范围不明确的请求，先估算数量、展示具体操作与边界并确认一次；无法枚举时提供有限范围，不请求无限授权。
- 一次授权累计涉及超过 20 个帖子的写操作，须确认。不能拆分多次工具调用规避累计限制。
- 确认绑定具体操作和目标集合/明确上界；超出范围重新确认。确认不授予永久权限。
- 授权必须在服务端检查，模型输出“用户已同意”不构成授权证据。

### R08：执行限额

| 项目 | 第一版默认值 | 计数含义 |
|---|---:|---|
| 模型请求 | 20 次/请求 | 包括重试与模型上下文压缩 |
| 业务工具调用 | 50 次/请求 | 包括模型触发的业务查询与写入尝试 |
| 执行总时长 | 15 分钟/请求 | 包含 Job 等待与执行期间等待确认 |
| 无额外批量确认的写操作范围 | 最多 20 个帖子/授权 | 同一授权累计，不能拆批绕过 |

程序查询 Job 状态不调用模型，也不消耗上述业务工具配额，但受独立轮询频率和总时长约束。限额可由宿主配置调整，Agent 不能修改。达到上限保存进展和已有 Job 信息，明确报告未完成；由用户决定是否继续，不自动开启新请求重置额度。

## 4. 会话、任务与停止

### R09：会话持久化

保存用户消息、模型消息、工具调用参数与结果、授权、关联 Job 和文件操作记录。页面显示文本不是唯一历史来源。浏览器断线、刷新或关闭后，执行继续；重连后恢复同一请求的状态、进度与最终结果。

同一会话一次只执行一个请求。新消息可排队，或由用户停止当前请求后重新发送；第一版不支持改变正在执行的计划。排队消息必须可见、可撤回，不能静默丢失。

### R10：创建任务与等待结果

- “归档这些帖子”：提交成功后可结束对话请求，说明仅已提交，并展示 Job 信息。
- “归档后帮我总结”：程序等待 Job 达到可读取结果的状态，再让模型继续读取和总结。
- 成功以 `read_job` / `wait_for_job` 的业务完成事实（包括 `result_ready`）为准，不能以创建成功或 HTTP 200 代替。
- 部分失败、超过等待上限或被停止，逐项保留已完成、未完成、结果待核实的状态。
- 不实现无限期后台推理或自动跨日续跑。

### R11：停止与重启

停止后不再发起新的模型和工具操作；尽可能取消正在进行的模型请求。已经进入业务执行的调用可能完成，须记录真实结果。已提交的 Job 不因停止对话被取消。

进程重启后，不自动恢复未完成推理；将未完成请求明确标记中断，保留历史并核查已提交操作。已有 Job 按现有机制恢复。尚未开始的排队消息保留但不自动执行，由用户重新发起。

### R12：重复提交与不确定结果

重复点击、网络重发不得创建第二个相同对话请求。写调用超时后先核查是否生效，不能盲目重试。对无法确认结果的操作显示“待核实”，阻止同一操作自动重放。仅有 Agent 层缓存不能视为崩溃场景的幂等保证。

## 5. 固定指导与上下文

### R13：独立业务 AGENTS.md

业务助手使用独立的 `AGENTS.md`，不加载仓库根目录面向编程 Agent 的开发指南。内容包括职责、固定偏好、工作规则及必要业务知识；工具参数与可用能力从受限 MCP 获取。

默认只读。用户明确说“把这个偏好写入 AGENTS.md”或“记住这个偏好”时，可以直接更新并展示差异，保留上一版本；含义不清时询问。不得从帖子、工具返回、模型推测中生成修改授权。

使用固定路径的专用更新能力，不借此开放任意文件写入。指导文件不能改变工具白名单、批量额度或程序权限；不在其中存储凭据。

### R14：会话上下文

第一版不自动跨会话检索对话或建立记忆库。长会话允许压缩提供给模型的上下文，但完整历史保留；帖子 ID、Job ID、授权范围、操作结果与未完成事项不能因摘要而丢失。摘要不是授权来源。

## 6. 本地文件能力

### R15：文件边界

Agent 使用独立持久化工作目录，通过 MCP 列出、读取、创建、修改和删除工作文件。不提供 Shell、任意路径读写或通过符号链接跳出工作目录的能力。

程序记录哪些文件由 Agent 创建，不能根据模型声明、文件名或所在目录推断归属。用户放入的文件默认只读；原始归档、数据库、配置和 Job 导出产物不属于可写范围。Agent 可以将允许读取的材料整理为新的工作文件。

### R16：修改与删除

- 当前请求所需的创建、修改直接执行；覆盖必须保留上一版本。
- 删除 Agent 文件须由用户明确要求，先移入回收区，不永久清除。
- 不自动清理其他会话文件。跨会话操作必须由当前用户请求明确指向目标，不能自动加载其他会话正文。
- 用户从外部替换或修改文件后，不得静默覆盖；应检测冲突并让用户决定。
- 文件操作需有记录和可见结果；指导文件独立适用 R13。

## 7. 数据与迁移

### R17：发送模型的数据

允许发送完成当前请求必要的帖子内容、作者信息和工具结果。Cookie、密钥、连接串等凭据不得进入模型上下文、前端响应、日志或指导文件。只按需读取内容，限制工具输出大小；论坛文本与文件内容均作为数据处理，不能覆盖宿主权限。

### R18：Hermes 迁移

验证期间保留明确的 Hermes 回退入口；新旧会话分开管理，不自动导入旧历史或把失败请求重发给另一个后端。旧会话仍通过 Hermes 查看。新方案验收后移除对话对 Hermes 的依赖；外部 Hermes 仍可作为独立 MCP 客户端。

## 8. 验收矩阵

下表是本次增量需求的验收基线，实施时应同步进项目[智能体验收标准](智能体验收标准.md)，不得把本规划标为已通过。

| 编号 | 场景 | 必须观察到的结果 |
|---|---|---|
| A01 | 查询、归档、归档后整理 | 三类真实任务按语义完成；提交与完成明确区分 |
| A02 | 关闭页面再打开 | 原请求继续，恢复记录，不重复执行 |
| A03 | 模型/MCP 不可用与恢复 | 有明确错误和恢复入口，不伪造成功 |
| A04 | 重复点击与写调用超时 | 请求去重；写结果先核查，不重复创建同一操作 |
| A05 | 停止和进程重启 | 不自动续推理，记录在途结果与存活 Job |
| A06 | 未允许工具、资源和参数 | 服务端拒绝，包括本地 HTML 输入与任意目标地址 |
| A07 | 超过 20 帖、拆批调用、范围改变 | 累计额度生效，授权不能越界或被重放扩权 |
| A08 | 20 次模型/50 次工具/15 分钟上限 | 停止后续执行并保留进展，程序等待不反复调用模型 |
| A09 | 写指导文件 | 无用户授权拒绝；有授权仅改固定文件并留版本 |
| A10 | 文件 CRUD | 归属、路径、只读输入、版本与回收区规则生效 |
| A11 | 路径穿越、链接、外部替换、重复文件请求 | 不越界、不静默覆盖、不因重试重复修改 |
| A12 | 排队与上下文压缩 | 同会话串行，排队可撤回，关键业务事实不丢失 |
| A13 | Hermes 回退 | 后端隔离，不自动重发已产生副作用的请求 |
| A14 | 数据边界 | 提示注入不改变权限，凭据不泄漏 |

性能验收使用同一模型服务和同类任务比较 Hermes 与内置模式，记录首个有效事件、首个模型文本、总完成时间和错误率。加载动画不算有效响应；不预设固定秒数承诺。
